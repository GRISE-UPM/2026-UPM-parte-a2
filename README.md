# Sesión 1 - Parte A

Esta parte trabaja con la clase `SubscriptionService`. Su especificación está en [`ESP-SubscriptionServiceSpecification.pdf`](ESP-SubscriptionServiceSpecification.pdf).

## Instrucciones

1. Realice un fork del repositorio <https://github.com/GRISE-UPM/2026-UPM-parte-a2>.
2. Clone en su ordenador el repositorio del que ha hecho el fork (el suyo, no el original).
3. Abra el proyecto en su entorno de desarrollo. El proyecto ya incluye JUnit y Mockito: no es necesario modificar el fichero `pom.xml`.
4. Lea la especificación: [`ESP-SubscriptionServiceSpecification.pdf`](ESP-SubscriptionServiceSpecification.pdf), que está en la raíz del repositorio.
5. Implemente el código indicado en la especificación, en la clase `SubscriptionService` (`src/main/java/es/upm/grise/subscriptionService/SubscriptionService.java`).
6. Realice un commit. El mensaje debe ser significativo.
7. Confeccione las pruebas de unidad usando JUnit, en la clase `SubscriptionServiceTest` (`src/test/java/es/upm/grise/subscriptionService/SubscriptionServiceTest.java`). Utilice Mockito si lo necesita.
8. Realice un commit. El mensaje debe ser significativo.
9. Realice un push al repositorio del que hizo el fork.
10. En GitHub, abra un pull request desde su fork hacia el repositorio original (`GRISE-UPM/2026-UPM-parte-a2`, rama `main`). Escriba su nombre y apellidos donde lo pide la plantilla del pull request.

## Normas

- Trabaje de forma individual.
- No utilice asistentes de inteligencia artificial (LLM) en esta sesión.
- No modifique el fichero `pom.xml`.
- Abra un único pull request al terminar esta parte y no realice más cambios después.
